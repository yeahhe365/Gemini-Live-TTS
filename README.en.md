## Overview

A real-time text-to-speech tool powered by the Gemini Live API.

## Features

- Realtime speech synthesis.
- Designed for Gemini Live API workflows.
- React frontend interface.
- Includes visualization and control components.

## Quick Start

- Enter `gemini-live-tts`.
- Run `npm install`.
- Configure Gemini API access and run `npm run dev`.

## Configuration

- Requires Gemini API credentials. Use the variable names expected by the app source.

## Tech Stack

- React
- TypeScript
- Vite
- Gemini Live API
