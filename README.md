## 项目简介

基于 Gemini Live API 的实时文本转语音工具。

## 核心功能

- 实时语音合成。
- 面向 Gemini Live API 工作流。
- React 前端界面。
- 包含图表和控制组件。

## 快速开始

- 进入 `gemini-live-tts`。
- 运行 `npm install`。
- 配置 Gemini API 后运行 `npm run dev`。

## 配置说明

- 需要可用的 Gemini API 凭据。具体变量名以应用源码中的配置读取逻辑为准。
